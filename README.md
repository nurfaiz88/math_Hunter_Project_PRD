## Math Hunter: STEM Education Adventure Game
Project Overview

Math Hunter is an educational platform-adventure game developed using Microsoft MakeCode Arcade. The game integrates mathematics learning with exploration, problem-solving, and action-adventure gameplay to create an engaging STEM learning experience for secondary school students.

Players must solve mathematical pattern and sequence challenges while navigating a platform world filled with obstacles, enemies, hidden paths, and boss encounters. The game combines curriculum-based mathematics with interactive gameplay mechanics inspired by classic side-scrolling adventure games.

## Educational Focus

The game is designed around Mathematics Form 3 (Tingkatan 3) concepts, particularly:
Patterns and Sequences

## Examples implemented in the game include:

Question	= Correct Answer
2,5,8,11,_	= 14
30,27,24,21,_	= 18
3,6,12,24,_	= 48
1,4,9,16,25,_	= 36
1,1,2,3,5,8,13,_	= 21

Questions are randomly selected each time the game starts, providing replayability and continuous learning opportunities.

## Use as Extension

This repository can be added as an **extension** in MakeCode.

* open [https://arcade.makecode.com/](https://arcade.makecode.com/)
* click on **New Project**
* click on **Extensions** under the gearwheel menu
* search for **https://github.com/nurfaiz88/math_Hunter_Project_PRD** and import

## Edit this project

To edit this repository in MakeCode.

* open [https://arcade.makecode.com/](https://arcade.makecode.com/)
* click on **Import** then click on **Import URL**
* paste **https://github.com/nurfaiz88/math_Hunter_Project_PRD** and click import
